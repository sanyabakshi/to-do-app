# ✏️ Cute To-Do List App 💖

* A simple yet cute and visually appealing To-Do list web application that helps user manage their daily tasks efficiently with cute and modern interface.
---

## 🚀 Features

* ➕ Add new tasks
* ✅ Mark tasks as completed using checkbox
* ❌ Delete tasks
* 🔍 Filter tasks (All / Completed / Pending)
* 💾 Data saved using Local Storage (persists after refresh)
* 🔢 Task counter (Total & Completed)
* ⌨️ Add task using Enter key
* 🎀 Cute pink UI with styled components

---
